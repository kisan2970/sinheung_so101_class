SO-101의 관절 6개

모터 6개 = 관절 6개

각 모터는 각도를 읽고, 원하는 각도로 이동할 수 있다

→ 로봇의 "자세" = 숫자 6개

지난 시간: 텔레오퍼레이션

leader 팔
(사람이 움직임)
각도 숫자 →
follower 팔
(똑같이 따라함)

사람이 계속 붙어 있어야 한다 → 사람 없이 혼자 하게 하려면?

공장 로봇은 어떻게 일을 배울까?

1
로봇을 원하는 자세로 옮긴다
2
버튼을 눌러 자세를 저장한다
3
저장한 자세들을 순서대로 재생

이 방법을 티칭(Teaching), 저장한 자세를 웨이포인트라고 한다

웨이포인트 = 경유하는 자세

1 큐브 위 → 2 내려가서 잡기 → 3 들어올리기 → 4 컵 위 → 5 내려놓기

로봇은 어떻게 부드럽게 움직일까?

갑자기 출발·정지하면 물건이 떨어지고 위험 → 가속·속도를 제한한다

teach.bat team1

로봇 없이 연습: teach.bat practice --sim

선생님 시범

  1. leader 팔로 큐브 위로 → s
  2. 내려가서 그리퍼 닫기 → s → w
  3. 들어올리기 → s
  4. 컵 위 → s, 그리퍼 열기 → s
  5. p 재생!

카메라 사진 1장
= 640 × 480 칸
= 약 30만 개 숫자 (×3 색)

이 숫자 더미에서 "손이 어디 있지?"를 찾는 것이 컴퓨터 비전

MediaPipe: 손 관절 21개 점

사진을 넣으면 손가락 마디 21개 점의 위치(x, y)를 알려준다

0 = 손목 · 4 = 엄지 끝 · 8 = 검지 끝
12 = 중지 끝 · 16 = 약지 끝 · 20 = 새끼 끝

주먹인지 어떻게 알까?

편 손: 손끝이 멀다

주먹: 손끝이 가깝다

손끝~손목 거리
÷ 손바닥 길이

주먹 ≈ 0.8
손가락 2개 ≈ 1.25
편 손 ≈ 1.7

나누는 이유: 손이 카메라에서 멀어져도 같은 값

━ AI가 본 값 (덜덜 떨림)   ━ 필터를 거친 값
